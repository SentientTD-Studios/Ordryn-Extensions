# Estimate

Manifest-only custom field. Registers `estimate.points` (Fibonacci enum) on project tasks. Core renders the sidebar dropdown and kanban badge.

## Install

1. Copy this directory to `data/extensions/estimate` (folder name must stay `estimate`).
2. Restart Ordryn.
3. Site admin: Admin → Extensions → Estimate → Enable, then Save.
4. Project owner: Project settings → Extensions → Estimate → Enable for this project, Save.

Safe to enable alongside Severity; this field is points, not severity.
