# Claimed

ntfy alerts for `task.claimed`, `task.unclaimed`, and `task.overdue`. Copy this folder to `data/extensions/claimed` (name must stay `claimed`), restart, enable in Admin → Extensions, then paste a public HTTPS topic URL.

On a project, members can use **Notify me** plus **Only when claimed by me** so the phone only buzzes for their cards. Skip-self is on by default for personal destinations.

LAN ntfy hosts are rejected (SSRF protection).
